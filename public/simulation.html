📖 How Bubble Sort Works

Bubble Sort is an elementary, comparison-based sorting algorithm. Its name stems from the way larger values gradually "bubble up" to the end of the array, like air bubbles rising in water, as repeated adjacent comparisons and swaps take place.

Mechanics

The Step-by-Step Cycle

In each pass through the array:

  • Traverse adjacent pairs from index 0 to n - i - 1.
  • If the left item is greater than the right item (arr[j] > arr[j+1]), swap them.
  • After pass i, the (i+1)th largest element is locked into its correct final sorted slot at the end.
Optimization

Early Exit Optimization

A standard bubble sort executes $\approx n^2 / 2$ comparisons regardless of initial array order. However, by tracking whether any swap happened during a pass, we can stop immediately if a pass finishes with zero swaps.

This drops the best-case time complexity to linear $O(n)$ on pre-sorted data.

Complexity

Time & Space Complexity

  • Worst Case: $O(n^2)$ (Array sorted in reverse order)
  • Average Case: $O(n^2)$
  • Best Case: $O(n)$ (With swapped flag optimization)
  • Auxiliary Space: $O(1)$ (In-place sort)
Properties

Stability & Practicality

Bubble sort is stable: identical elements never swap past each other because elements are only swapped when one is strictly greater (>).

While easy to understand, it is rarely used in production due to quadratic performance compared to $O(n \log n)$ algorithms like Quick Sort or Merge Sort.
